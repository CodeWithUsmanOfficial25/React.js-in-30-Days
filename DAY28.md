# Day 28 — NEBULA

A high-motion cosmic experience studio built with React and CSS 3D effects.

## Experience
- Large animated cosmic sphere with layered 3D-style orbital rings.
- Independent orbital satellites, floating particles and cosmic light streaks.
- Kinetic multi-line typography and continuous marquee.
- Large animated ambient lighting and moving background layers.
- Claymorphism and neumorphism-inspired cards and controls.
- Interactive mission cards, exploration profiles and energy slider.
- Live clock and rotating signal feed.
- Responsive layouts for desktop, tablet and mobile.

## Run locally
```bash
npm install
npm run dev
```

The displayed cosmic metrics and mission signals are illustrative frontend data. The project does not connect to real space telemetry.
