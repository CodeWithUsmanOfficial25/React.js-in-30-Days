# Day 27 — TERRAFLUX

A 3D-inspired planetary intelligence and eco-tech command center.

### Experience
- Animated 3D-style rotating planet with atmospheric glow and orbital rings.
- Kinetic typography, floating elements, moving energy routes and glowing nodes.
- Claymorphism, neumorphic controls and layered glass-inspired surfaces.
- Interactive regional network selection.
- Adjustable energy distribution and operation profiles.
- Live clock, activity stream and responsive layouts.
- Blue, green and earthy brown lighting system.

### Run
```bash
npm install
npm run dev
```

Note: This is a frontend simulation using illustrative sample data, not a real environmental monitoring service.
