# VeloVault — Premium Multi-Vehicle Showroom

Day 18 of the 30-Day React learning journey.

A standalone, responsive vehicle showroom built with HTML5, CSS3 and vanilla JavaScript.

## Categories

- Cars
- Motorcycles
- Buses and coaches
- Bicycles
- SUVs
- Trucks and pickups
- Electric vehicles

## Features

- 42 vehicle models
- Three configurations for every vehicle
- Vehicle-specific details and specifications
- Category filtering
- Live search
- Interactive vehicle details modal
- Variant selector
- Responsive layouts
- Claymorphism and neumorphic styling
- Direct remote vehicle image loading
- Automatic image fallback
- Keyboard-accessible vehicle cards

## Project Structure

```text
Day18-Vehicle-Showroom/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run

Open `index.html` in a modern browser.

No build step, package installation or local image downloads are required.

## Images

Images are requested directly from LoremFlickr at runtime. A Placehold image is used if the remote image fails.

An internet connection is required for remote images and Google Fonts.

## Notes

Vehicle prices and technical specifications are illustrative demonstration data. Verify manufacturer specifications and local market prices before making purchasing decisions.
