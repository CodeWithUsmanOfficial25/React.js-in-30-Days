# React.js in 30 Days

## Day 14 — Veloce Automotive Studio

A premium automotive customization experience built with React and CSS.

### Features
- Interactive car paint customization
- Wheel style selection
- Optional performance, interior and carbon packages
- Live estimated build pricing
- Consultation booking modal
- Responsive layout
- CSS 3D-inspired car visualization, showroom lighting and motion
- Claymorphism and neumorphic UI surfaces

### Tech
- React
- Vite
- CSS animations
- React state and event handling

### Run
```bash
npm install
npm run dev
```

Note: This is a frontend concept/demo. Booking requests are handled locally and are not sent to a real dealership.
