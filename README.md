
# React.js in 30 Days 🚀

A practical 30-day journey to build React.js skills through structured code, reusable components, and progressively more advanced frontend projects.

This repository contains daily implementations that demonstrate React concepts through working interfaces rather than notes alone.

## 🎯 Goals

- Build a strong foundation in React and JSX.
- Understand components, props, expressions, and rendering.
- Practice reusable UI architecture and clean code organization.
- Develop responsive interfaces with CSS.
- Progress toward practical frontend and full-stack development.

## 🛠️ Technologies

- React
- JavaScript (ES6+)
- JSX
- CSS3
- Vite
- npm
- Git and GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/CodeWithUsmanOfficial25/React.js-in-30-Days.git
cd React.js-in-30-Days
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
