# React.js-in-30-Days

A 30-day practical React learning journey, built with Vite.

## Day 30 — AURORA OS

A multi-module business workspace and enterprise-style SaaS dashboard experience.

### Modules
- Command Center
- Analytics Studio
- Project Hub
- CRM Suite
- Finance Center
- Team Workspace
- Automation Lab
- Asset Library
- Settings and Profile

### React concepts demonstrated
JSX, reusable components, props, composition, lists and keys, conditional rendering, event handling, controlled forms, array and object state updates, lifting state, useState, useEffect, React Router, Context API, useRef, custom hooks, useMemo, useCallback, useReducer, React.memo, loading states, localStorage persistence, responsive UI and reusable component architecture.

### Stack
- React
- Vite
- React Router
- JavaScript
- CSS
- Browser localStorage

### Run locally
```bash
npm install
npm run dev
```

### Production build
```bash
npm run build
```

This is a frontend portfolio demonstration. It uses sample workspace data and simulated interactions. Authentication, real payment processing, external APIs, file uploads and persistent multi-user services require a backend integration.
