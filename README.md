
# React.js in 30 Days 🚀

My 30-day journey to learn React.js through practical coding, daily programs, and progressively challenging projects.

This repository documents my progress from React fundamentals to building reusable components and complete React applications.

## 🎯 Goals

- Understand React fundamentals and JSX.
- Build reusable components and work with props.
- Manage state and handle events.
- Use hooks such as `useState` and `useEffect`.
- Work with APIs and asynchronous data.
- Learn React Router and form handling.
- Build practical frontend projects.
- Develop a foundation for full-stack web development.

## 🛠️ Technologies

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Git and GitHub

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/CodeWithUsmanOfficial25/React.js-in-30-Days.git
```

Move into the project directory:

```bash
cd React.js-in-30-Days
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
